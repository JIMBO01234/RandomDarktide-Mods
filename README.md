Overall Info:
All credit for the Base mods go to the original creators, my goats fr, i'm just doing some stuff to adjust them to my tastes.

The Havoc Boss trigger mod uses code from the Strikemap and the Respawn Rewind mod. 

WHAT DO THEY EVEN DO??

HavocBossTriggers: marks boss and daemonhost spawn points and the path triggers that set them off, so you can see where the next boss will spawn.
MedSkullRange: Made with alfs markers AIO in mind, shows you if a downed ally is in med skull range and available to be resd (not behind a rock etc).
NumericUI	Fixed for Darktide 1.13.0, with repaired ability/blitz cooldown timers, a per-charge teammate ability bar, a “percent for Skitarii” cooldown format and an ammo text colour setting.
PlayerOutlines_ClassColors	Adds class-based outline colours: one shared default colour plus optional per-class RGB overrides.
RecolorBossHealthBars: boss nicknames and “the Bonker”/”the Slasher” Captain weapon names with their own name and bar colours.
ToggleRevive: press interact once to revive, rescue, pull up or un-net a teammate instead of holding.
Transonic_Stance_Colors_lightened: Lighter on performance than the og mod.
big_e_protects: it shows a Holy Revenant status icon with position, size and opacity settings.
i_wanna_see_2	: a “disable while playing Psyker” toggle, a flamer sound volume slider, and colour and brightness settings for the Psyker shield floor radius.
inventory_crafting: adds Hadron crafting buttons to the inventory plus Quick Mastery, which buys weapons from Brunt’s Armoury to level mastery.
ovenproof_scoreboard_plugin	Adds a “toughness shared” scoreboard row, using an estimate adapted from Overflow Meter so that mod isn’t required.
pingsmokelocation: automatically pings where the Veteran’s smoke grenade lands or explodes.
